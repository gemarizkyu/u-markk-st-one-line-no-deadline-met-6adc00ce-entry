A small deterministic program that writes one single-line joke excusing a
missed deadline. It scores six hand-written candidate excuses against the
judge's published brief — a real excuse, a real joke with a turn, one
sentence that lands its punch at the end, a human voice, a fresh angle —
and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program needs no network, no API key, and no randomness: the same run
always writes the same line.

Example output:

> I finished it on time, but my laptop updated, restarted, and emailed you a blank file called final_FINAL_v2_I_mean_it_this_time — so the deadline died of embarrassment.
